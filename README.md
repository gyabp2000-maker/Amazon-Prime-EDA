# Amazon Prime Video — Exploratory Data Analysis

A data analytics portfolio project exploring Amazon Prime Video titles, genres, release years, ratings, production countries, and cast and crew.

## Project file

[Open the EDA notebook](notebooks/Amazon_Prime_EDA.ipynb)

## Tools and analysis

Python, Pandas, NumPy, Matplotlib, and Seaborn. The notebook includes data inspection, missing-value and duplicate checks, feature engineering, visualizations, and written observations. It explores catalog composition, release trends, genres, runtime, IMDb ratings, TMDB popularity, and cast and crew.

## Run the notebook

1. Download the notebook and open it in Google Colab.
2. Put the original `titles.csv` and `credits.csv` datasets in the root of your Google Drive's My Drive folder.
3. Run the import and loading cells, authorizing the Drive mount when prompted.
4. Run the remaining cells to generate the analysis and charts.

The loading cells use `/content/drive/MyDrive/titles.csv` and `/content/drive/MyDrive/credits.csv`. Update these paths if your datasets are stored elsewhere. Raw datasets and saved notebook outputs are not included in this repository.

## Interpretation

This is an exploratory portfolio project based on a supplied catalog snapshot. Associations in ratings or popularity do not establish causation or business impact.
