# Python Programming Capstone

This notebook contains programming exercises completed as part of an introductory Python capstone, including problem solving with variables, conditionals, loops, functions and other programming fundamentals.

[Open the notebook](Programming_Capstone.ipynb)

## Notebook provenance

This is a GitHub-optimized copy of `Capstone_Project_Introduction_to_Computer_Programming1.ipynb`, supplied by the project author. It retains the original 98 code cells and written exercises. Thirty-one large inline images and GIFs were replaced with short placeholders to keep the GitHub file small and readable. The original uploaded notebook remains unchanged.

## How to run

Open the `.ipynb` file in Jupyter Notebook or Google Colab and run cells in order. Any resources referenced by individual exercises may require their original accompanying files.
